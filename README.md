# Yanyun Equipment Manager

燕云十六声装备管理小工具项目。

## 目标

这个工具用于管理多流派装备 benchmark 和玩家已有装备，回答：

- 某个流派毕业装备需要哪些词条，以及这些词条应分布在哪些部位。
- 一件已有装备匹配哪些流派，达到毕业、接近毕业或过渡水平。
- 一组装备覆盖了多少流派，哪些装备适合作为跨流派继承装备保留。
- 当前装备距离目标 benchmark 还差哪些关键词条。

## 当前阶段

当前先沉淀领域规则和数据标准，后续再实现：

- benchmark 配置录入
- 图片/OCR 辅助录入
- 装备录入
- 装备评分与流派覆盖统计
- 可视化管理页面

## 文档

- `docs/domain-constraints.md`：装备部位、词条来源、词条池等领域约束。
- `docs/benchmark-rules.md`：从总词条数量反推部位分配的规则。
- `data/benchmark-samples.md`：已确认的 benchmark 样例。

## 数据文件

- `data/benchmarks.current.json`：只记录截图中每个流派方案的词条数量 benchmark，后续换图主要改这个文件。
- `data/slot-recommendations.current.json`：记录基于 benchmark 推导出的每个装备部位必选词条、可选词条池、全身计数要求。

## 数据分层原则

- benchmark 文件只负责“目标总量”，例如 `12大外 + 10劲 + 2精准 + 6会心`。
- recommendation 文件负责“部位约束”，例如左边 4 件初始大外、8 件调律大外、腕甲胫甲初始劲。
- 会心、精准、会意等灵活词条不写死唯一落法，只记录全身必须凑够的数量。
- 破竹、裂石、牵丝、无相、势等伤害补位词条按数量和可选池识别，后续如确认更精确部位池再收紧。
