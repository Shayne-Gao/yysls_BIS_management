# 领域约束

本文记录燕云十六声装备管理工具当前采用的领域规则。

## 装备部位

一套装备按 8 个部位管理：

- 左边 4 件：主武器、副武器、佩、环
- 右边 4 件：头、衣服、腕甲、胫甲

## 词条来源

每件装备的有效词条来源分为：

- 初始词条：装备天然自带的首词条。
- 调律词条：通过调律追加出的词条。

工具在计算 benchmark 时必须区分词条来源，因为不同部位的初始词条池不同。

## 初始词条池

当前采用的初始词条池：

| 部位 | 初始词条池 |
| --- | --- |
| 武器 | 最大外功攻击、最小外功攻击、最大本系属功、最小本系属功、敏、势 |
| 佩 | 最大外功攻击、最小外功攻击 |
| 环 | 最大外功攻击、最小外功攻击 |
| 头 | 会心率、会意率、精准率、最大气血、外功防御 |
| 衣服 | 会心率、会意率、精准率、最大气血、外功防御 |
| 腕甲 | 会心率、会意率、精准率、劲、体、御、最大气血、外功防御 |
| 胫甲 | 会心率、会意率、精准率、劲、体、御、最大气血、外功防御 |

## 关键推论

- `最大外功攻击` 和 `最小外功攻击` 可以作为左边 4 件的初始词条。
- `最大外功攻击` 和 `最小外功攻击` 不能作为右边 4 件的初始词条，只能通过调律出现。
- `会心率`、`会意率`、`精准率` 可以作为右边 4 件的初始词条。
- `劲` 可以作为腕甲、胫甲的初始词条，也可以作为调律目标词条。
- 词条统计必须避免把同一件装备的同名词条重复来源混淆；同名词条可以同时来自初始和调律，但每个来源都要单独计数。

## 特殊词条位置

当前采用的特殊词条位置约束：

| 词条类型 | 推荐出现部位 | 说明 |
| --- | --- | --- |
| 武器/武学专属增伤 | 武器 | 例如 `手甲`，通常作为对应武器或武学的专属增伤词条 |
| 全武学增效 | 佩、环 | benchmark 中通常记作 `全武` |
| 首领增伤 | 腕甲、胫甲 | benchmark 中通常记作 `首领` |
| 属功/外系词条 | 调律词条 | 例如 `破竹`、`无相`，按 benchmark 数量统计 |

如果后续从游戏内截图确认某个特殊词条的出现部位不同，以截图规则覆盖本文。

## 装备保存原则

工具默认按跨流派继承价值判断装备：

- 优先保留能覆盖多个流派 benchmark 的装备。
- 左边 4 件优先关注大外、小外、敏、势等可作为初始词条的胚子价值。
- 右边 4 件优先关注三率和劲的胚子价值。
- 某件装备即使不适配当前流派，也可能适配其他流派，不应只按单一流派淘汰。
